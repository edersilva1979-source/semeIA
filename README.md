# SemeIA

Landing page demonstrativa do projeto SemeIA, um conceito de sistema para apoiar produtores de arroz com sensores, mapa por quadras, geolocalização, controle de custos e projeção de safra.

## Arquivos

* `index.html` página Home
* `sobre.html` página Sobre
* `contato.html` página Contato
* `cadastro.html` página Cadastro
* `styles.css` estilos responsivos
* `script.js` menu mobile, animações, contadores, FAQ e formulários demonstrativos
* `assets/semeia_mascote.png` mascote oficial fornecido para o projeto
* `assets/folha.svg` ícone de folha do logotipo

## Como publicar

Envie todos os arquivos mantendo a mesma estrutura de pastas para um serviço de hospedagem estática como GitHub Pages, Netlify ou Vercel.

A página inicial é `index.html`.

## Formulários

Os formulários são apenas demonstrativos. O JavaScript impede o envio real e exibe uma confirmação local no navegador. Para uso comercial futuro será necessário conectar os formulários a um backend, banco de dados, CRM ou serviço de email e implementar os requisitos de privacidade e LGPD.

## Fotografias

O site utiliza fotografias remotas do Unsplash como apoio visual. Em uma versão comercial, é recomendável revisar as imagens finais, os créditos desejados e a identidade fotográfica do produto.
